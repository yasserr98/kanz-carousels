# Kanz explainer design library

This package contains finished examples, editable visual layouts, fonts and artwork. Supply separately approved copy; this package contains no writing prompts or voice instructions.

1. Extract the complete ZIP and open index.html.
2. Duplicate a layout from layouts/ and keep relative asset paths intact.
3. Place approved text and imagery in the existing visual layout. Keep text editable.
4. Check font loading, Arabic joining, image crops and source credits at phone size.
5. Render at the layout dimensions and review before publishing. Do not add decorative slide counters.

Use genuine website screenshots and original book covers. Source credits are retained under notes/; examples are delivered work, not automatic approval for future publication.
