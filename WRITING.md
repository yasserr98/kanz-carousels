# Basic writing guidance

This is a generic optional drafting step. It does not contain Yasser's writing method, personal Arabic voice, reusable prompts or caption formulas.

1. Ask for the topic, intended audience, language, source facts and desired number of slides when these are missing.
2. Use plain, neutral language. Present one main point per slide and keep text concise enough for the selected layout.
3. Verify names, dates and numbers against the supplied sources. Mark unresolved facts for review rather than inventing details.
4. Do not imitate a named person's voice or infer a writing style from the finished examples. Examples are visual references.
5. Show the draft for approval before production. If approved copy is provided, use it as supplied and ask before substantive changes.

After approval, follow START-HERE.md and the selected library's HOW-TO.md for design, rendering and review. No additional writing system is required or included.
